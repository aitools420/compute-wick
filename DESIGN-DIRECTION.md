# Design direction — committed 2026-08-23

**Read:** product landing + live market surface, for technical buyers and AI agents,
industrial-naturalist language, native hand-written CSS. Dials: VARIANCE 7, MOTION 5, DENSITY 5.

**The one direction: a field station at the edge of a pond, at night.**
Swamp-dark stock (green-black temperature, never pure black). Instrument mono for every
number. Editorial serif for display and the field-note voice. Real frog photography
(bioindicator = the product's own idle index). Baked-grain overlay for print feel.

**The one memorable moment:** the hero pond. A canvas field of drifting motes over dark
water, one mote per REAL live offer from /api/stats, phosphor-green motes = idle
capacity. Legend states it plainly. Reduced motion = same canvas drawn once, static.
Pauses off-screen and on hidden tabs.

**Type:** Erode (Fontshare, ITF FFL) 400/600 for display + field notes. Martian Mono
(Google, OFL) variable for numerals, labels, tables, code. Body copy: system sans stack
(deliberate). Every family list ends in a generic.

**Palette:** stock #0C110E; raised #121814; ink #E8EDE9; secondary ink #A8B3AA;
hairlines rgba(232,237,233,0.14). Accent: firefly amber #F5A97F-family for display
emphasis + CTAs (display token + darker ink token if needed at small sizes).
Phosphor green #7FD99A RESERVED: it only ever marks idle capacity / live state.
Green never decorates.

**Radius system:** all-sharp (0) except pill chips/buttons (999px) — documented rule:
interactive pills, everything else square.

**Layout families (no repeats):** full-bleed canvas hero → full-width data surface
(live market) → narrow centered schematic (how it works) → split editorial spread
(frog / idle index) → stacked prose + wide code panel (agents) → manifesto strip
(fees) → footer.

**Bans honored:** zero em/en dashes anywhere on the page; max 2 eyebrows total
(7 sections); no scroll cues; no decorative dots (green dot = real live state only);
no fake numbers (every stat is the live API); no div-fake screenshots (the market
table IS the product, live); one accent; one theme (dark, locked).
